# 互维云+远程打印助手

一个针对 CUPS 开发的云打印系统，让你的老旧打印机也能支持微信小程序云打印。微信搜索「互维云+」即可找到小程序；Docker 内含专属云 ID，小程序扫码即可添加设备。

- 支持 **x86 与 ARM** 架构，基于 Docker 部署，飞牛 fnOS 应用中心一键安装。
- 兼容 USB 打印机与局域网（mDNS 发现）打印机。

## 使用方式

1. 在飞牛 fnOS 应用中心添加本应用源并安装「互维云+远程打印助手」。
2. 安装时可设置 CUPS 管理员密码（默认用户 `root` / 密码 `admin123`）。
3. 打开微信，搜索小程序「互维云+」，扫码添加设备即可使用云打印。

## 管理页面

将 `ip` 替换为你的设备 IP：

| 地址 | 说明 | 账号 / 密码 |
| --- | --- | --- |
| `http://ip:8088` | 设备管理页面（查看设备 ID） | — |
| `http://ip:631` | CUPS 页面 | 用户 `root` / 密码 `admin123` |
| `http://ip:8080` | cups-web 页面 | 用户 / 密码均为 `admin` |

## 说明

- 应用采用 host 网络 + USB 直通方式运行，以兼容局域网打印机自动发现与 USB 打印机。
- 首次启动需要拉取 Docker 镜像，请耐心等待；容器由飞牛系统自动管理。
